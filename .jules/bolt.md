## 2025-10-27 - Legacy Loop Unsubscribe Bug
**Learning:** The legacy `RAFClass` in `pages/about.html` (and likely others) has a bug in `unsubscribe`: `splice(i, i + 1)`. This deletes `i+1` elements starting from `i`, instead of `1` element. This makes `unsubscribe` dangerous to use if there are multiple subscribers.
**Action:** When interacting with legacy code, assume it might be broken. For `Loop.js` refactor, I used `unsubscribe` by name, which mitigates the risk if I am the last one or if I don't care about others being removed (though `i+1` suggests it removes more than intended). In my case, `modernLoop` is likely added last, so `i` is high, so `i+1` is large, wiping out everything after it. Since I am adding it to `RAF` at the end, and `unsubscribe` is rarely called (only on `stop()`), this risk is acceptable for now but noted.
