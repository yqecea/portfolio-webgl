До изменений проверен публичный сайт. Кандидат собран в `dist/` и проверен в Firebase Hosting Emulator. Код основан на `origin/master` с коммитом `5a56d24`.

## Что воспроизведено и исправлено

| Дефект | Что показала повторная проверка |
| --- | --- |
| Заставка на живом сайте закрывалась указателем. В её DOM отсутствовал доступный элемент входа. | Tab доходит до кнопки входа. Enter открывает главную и ставит фокус на ссылку About. Меню закрывается по Escape и возвращает фокус. |
| Мобильная галерея блокировала вертикальный свайп. На широком сенсорном экране два контроллера меняли одну галерею. | Chrome прокручивает карточки нативным touch-жестом при 360, 430 и 1024 px. Десктоп сохранил горизонтальное колесо и доступ к последней карточке с клавиатуры. |
| Живой `/work` возвращал 200, но раскрывал ссылку на `/about.html`, который возвращал 404. | В эмуляторе проверены четыре коротких адреса и четыре файловых адреса. Меню из `/work` приводит к `/pages/about.html`. |
| При 430 px с reduced motion живой сайт всё равно создавал WebGL canvas. Ошибка загрузки Three.js могла прервать инициализацию страницы. Старый обработчик восстановления повторно добавлял геометрию. | В режиме reduced motion работает статичная сфера без canvas. При блокировке Three.js остаются статичный экран и рабочие ссылки. Настоящее событие потери WebGL-контекста включает замену, затем сцена восстанавливается с одним canvas. |
| Three.js r125 использовала `Function()` и не работала со строгим CSP. | Three.js r187 из локального модуля рисует сферу без `unsafe-eval` и `unsafe-inline` в `script-src`. На телефоне тест использует SwiftShader и замедление CPU в 4 раза. |
| Hosting Emulator отдавал `AGENTS.md` из корня, несмотря на список исключений. | Сборка включает только файлы сайта. В эмуляторе `/AGENTS.md` и тестовый файл возвращают 404. Неизвестный адрес показывает фирменную страницу с HTTP 404. |
| В меню были незакрытые обёртки и ошибки доступных подписей. | HTML-валидатор проходит. Axe по WCAG A/AA не нашёл нарушений в проверенных состояниях. В обычных сценариях Chrome не сообщил ошибок консоли. |

## Команды

- `npm ci --no-fund` и `npm audit --audit-level=moderate` завершились с кодом 0. Аудит npm показал 0 уязвимостей.
- `npm run build` завершилась с кодом 0. Результат лежит в `dist/`.
- `npm run verify` завершилась с кодом 0 и создала отчёт и снимки в Chrome. Для нативной проверки задан `PORTFOLIO_BASE=http://127.0.0.1:5000` при запущенном Firebase Hosting Emulator.
- `npm run lint:links` завершилась с кодом 1. Все 10 работ открылись с HTTP 200. LinkedIn вернул 999 в HTTP-клиенте и в Chrome.

На физических телефонах, в Safari и на опубликованной сборке кандидат ещё не проверялся. Нет полевых данных INP. Права на существующие материалы подтверждены владельцем. Частные условия разрешения отдельно не проверялись.

